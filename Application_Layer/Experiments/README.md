## 04 – Application layer

Small scripts related to application-layer protocols.

### Subfolders

- **`smtp_socket_sim/`**: simple SMTP-like conversation simulated over raw sockets
- **`smtp_ethereal/`**: sending SMTP email using Ethereal test SMTP (via `smtplib`)
- **`ftp_client/`**: basic FTP client using Python `ftplib`
