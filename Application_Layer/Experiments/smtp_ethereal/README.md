## SMTP using Ethereal (test SMTP)

### Table of contents

- [Program](#program)
- [Notes](#notes)
- [How to run](#how-to-run)

### Program

- **`smtp_ethereal_send.py`**: sends an email using an Ethereal test account via `smtplib`

### Notes

- This is for **testing only** (Ethereal provides disposable SMTP inboxes).
- You’ll need Ethereal credentials (email + password) when running the script.

### How to run

```bash
python smtp_ethereal_send.py
```
