## Half-duplex (TCP)

### Table of contents

- [Programs](#programs)
- [How to run](#how-to-run)

### Programs

- **`half_duplex_server.py`**: receives one message first, then replies
- **`half_duplex_client.py`**: sends one message first, then receives reply

### How to run

In terminal 1:

```bash
python half_duplex_server.py
```

In terminal 2:

```bash
python half_duplex_client.py
```
