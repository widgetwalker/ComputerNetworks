## 02 – Duplex communication (chat)

Duplex chat examples using TCP sockets.

### Table of contents

- [Overview](#overview)
- [Subfolders](#subfolders)

### Overview

This experiment illustrates:

- **Half-duplex**: one side sends, then the other replies (turn-based)
- **Full-duplex**: both sides can send/receive simultaneously (threaded)

### Subfolders

- **`half_duplex/`**: half-duplex chat (server sends/receives in turn)
- **`full_duplex/`**: full-duplex chat (simultaneous send/receive)

Each subfolder has a `README.md` with concrete run commands.
