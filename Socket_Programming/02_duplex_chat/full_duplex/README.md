## Full-duplex (TCP)

### Table of contents

- [Programs](#programs)
- [How to run](#how-to-run)

### Programs

- **`full_duplex_server.py`**: threaded send/receive server (type `bye` to exit)
- **`full_duplex_client.py`**: threaded send/receive client (type `bye` to exit)

### How to run

In terminal 1:

```bash
python full_duplex_server.py
```

In terminal 2:

```bash
python full_duplex_client.py
```
