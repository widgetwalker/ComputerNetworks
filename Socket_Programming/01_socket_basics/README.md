## 01 – Socket basics

Simple TCP and UDP socket programs.

### Table of contents

- [Overview](#overview)
- [Subfolders](#subfolders)

### Overview

These examples introduce the difference between:

- **TCP**: connection-oriented communication
- **UDP**: connectionless datagrams

### Subfolders

- **`tcp/`**: basic TCP server/client chat and request–response
- **`udp/`**: basic UDP message exchange

Each subfolder contains a small `README.md` with exact run commands.
