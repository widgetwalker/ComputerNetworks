## TCP examples

### Table of contents

- [Programs](#programs)
- [How to run](#how-to-run)

### Programs

- **`tcpserver.py` / `tcpclient.py`**: interactive TCP chat (type messages back and forth)
- **`server.py` / `client.py`**: minimal one-shot TCP request/response demo

### How to run

In terminal 1:

```bash
python tcpserver.py
```

In terminal 2:

```bash
python tcpclient.py
```

For the minimal demo, run `server.py` first, then `client.py`.
