# ⚡ Cisco Packet Tracer Simulations

Network topologies and configurations designed for Cisco Packet Tracer.

---

## 📐 Network Topologies

### 🔹 Basic Connections
- `ex_1_1_connecting_2_pcs.pkt`: P2P connection.
- `ex_1_2_star_topology.pkt`: Star network using a central switch.

### 🔹 Routing
- `ex_1_3_1_basic_routing.pkt`: Simple router configuration.
- `ex_1_3_2_static_routing_3_routers.pkt`: Static routing tables across multiple router hops.
- `ex_6_pc_to_router.pkt`: Gateway configurations.

### 🔹 Switching & Vlan
- `ex_3_vtp_server.pkt`: VLAN Trunking Protocol (VTP) simulation.
- `lab3_20nc.pkt`: Large scale network configuration.

---

## 🛠️ How to View
1. Install **Cisco Packet Tracer**.
2. Open the `.pkt` files directly.
3. Use the **Simulation Mode** to watch ICMP/TCP packets traverse the network.
