## 03 – Reliable Data Transfer (ARQ simulations)

Simplified lab-style simulations of ARQ mechanisms.

### Table of contents

- [Mechanisms](#mechanisms)
- [Notes](#notes)

### Mechanisms

This folder contains:

- **Stop-and-Wait**
- **Go-Back-N**
- **Selective Repeat**

Each mechanism has its own subfolder and `README.md` with run commands.

### Notes

Most examples use **UDP sockets** and include timeout/retransmission and/or manual ACK dropping to demonstrate behavior.
